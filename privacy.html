Privacy Policy for Lumina Vista

Last updated: October 17, 2026

Application Overview

Lumina Vista ("we", "our", or "us") operates as a private productivity and workspace application. This application provides a personal unified operations hub—including autonomous AI assistant studio, cloud developer sandbox, IoT hardware telemetry, interactive whiteboard, and Google Calendar scheduling.

This policy describes our strict protocols regarding the collection, processing, and protection of user data, specifically through integrations with third-party APIs such as the Google Calendar API.

Data Collection & Google Calendar API Integration

We connect with Google Calendar API solely to display, synchronize, and manage your personal calendar events within your private dashboard interface.

  • Authorized Scopes: We request access strictly to https://www.googleapis.com/auth/calendar (to read and synchronize personal calendar events) and identity verification scopes (userinfo.email, openid).
  • Scope Limitation: We only access calendar metadata (event titles, start/end timestamps, descriptions, locations) necessary to render your calendar within Lumina Vista. We do not inspect personal contacts, emails, or unrelated Google account data.

Data Usage & Third-Party Sharing Restrictions

Your calendar data is processed in-memory or securely cached to provide scheduling features. We do not sell, share, or transfer your Google user data to any third parties.

  • Zero Third-Party Advertising: No data obtained through Google APIs is ever shared with, sold to, or used by advertisers, data brokers, or marketing networks.
  • Zero AI Model Training: Google Calendar data is never used to train generalized artificial intelligence or machine learning models.
  • Single-Tenant Boundary: Event data is accessible solely within the private authenticated session of the account owner.

Google API Limited Use Disclosure

Lumina Vista's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data Storage, Encryption & Security

Authentication tokens are stored securely in encrypted server-side state (such as Upstash Redis) and are used strictly for authorized calendar synchronization.

TLS 1.3 In-Transit All network communications between the browser, serverless endpoints, and Google API servers are encrypted using modern TLS 1.3.
Encrypted Server State OAuth refresh tokens are encrypted at rest with partitioned isolation in protected Redis cloud infrastructure.
Partitioned Cookies Session identifiers utilize HttpOnly, Secure, and SameSite=None attributes with CHIPS partitioning.
Zero-Trust Boundaries Strict constant-time cryptographic token verification safeguards all administrative entry points.

Data Retention, Revocation & Deletion

You have complete sovereignty over your data and Google integration:

  • Revoking Access via Lumina Vista: Click the Calendar sync badge in the dashboard header, open the Sync Modal, and click Disconnect Google Account. All cached access tokens, refresh tokens, and synchronization keys are instantly purged from the server state.
  • Revoking Access via Google: You can immediately revoke Lumina Vista's access at any time via your Google Account Permissions page.
